# Site Dra. Maria Fernanda Vieira Bruno

Experiência institucional cinematográfica para Dra. Maria Fernanda Vieira Bruno.

## V3 — referencia interativa

- Experiência principal em palco fixo e cenas controladas pelo scroll.
- Movimento de câmera simulado com perspectiva, escala, rotação e parallax.
- Tipografia e retratos coreografados em transições contínuas.
- Conteúdo sobre Legal Ops, Direito Bancário e Recuperação de Créditos.
- Layout responsivo para desktop e mobile.

## Estrutura

- index.html: layout, conteúdo, animações e interações.
- assets/: retratos profissionais otimizados em SVG autocontido.
